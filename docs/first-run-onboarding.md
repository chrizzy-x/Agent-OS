# First-Run Onboarding

Phase 08 defines onboarding as an action board, not a marketing page.

## Required actions

- Start a chat opens Super AgentOS in NL Studio and creates or reuses workspace context.
- Create a project opens the project creation flow.
- Install an app opens Appstore discovery.
- Install a skill opens Skill Store discovery.
- Create a subagent opens the incognito subagent creation surface.
- Connect a tool opens Universal MCP connector health and tool availability.

## Retail path

Retail onboarding focuses on using the workspace:

- Super AgentOS and NL Studio
- Projects
- Appstore
- Skill Store
- Library
- Vault
- Workflows
- Subagents
- Universal MCP visibility

## Enterprise path

Enterprise onboarding adds developer setup without exposing it as retail functionality:

- Developer Console
- SDK access
- App listing setup
- Skill listing setup

Retail users see enterprise setup as gated unless they move to Enterprise Plus or Enterprise Max.

## Data discipline

- Onboarding must not show fake installs, fake projects, fake workflows, fake tools, or fake enterprise access.
- Actions either navigate to a real surface, run a real backend action, or show a disabled reason.
- Universal MCP setup is introduced as connector health and tool availability until full connection setup is implemented.
