# FFP Disabled Surface

FFP is visible in AgentOS as a future Fabric Furge Protocol surface, but it is disabled in this build.

## What exists now

- `/ffp` is a visible product surface.
- FFP pages explain the future role of protocol-backed coordination.
- Compatibility endpoints can expose historical compatibility rows when they exist.
- All compatibility rows must be labeled as disabled records.

## What does not exist now

- No active FFP protocol routing.
- No validator dashboard.
- No proof events.
- No transactions.
- No consensus engine.
- No proposal execution.
- No activation control.
- No decentralization claim.

## Runtime rule

Multi-agent execution continues through the Unified Execution Engine. AgentOS must not present compatibility data as live FFP consensus, validators, proofs, transactions, or settlement.
